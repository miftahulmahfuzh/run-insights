## Goal

Below `lg`, `AdminNav` renders one 56 px row of seven icon-only cells — real Lucide path data inlined in the file, each link named by its `short` string as an sr-only accessible name — instead of the two-row 4x2 text grid. `app/admin/layout.tsx`'s `<main>` reserve returns from `8rem` to `5rem` in the same change, `tests/admin.shell.test.ts` re-pins the whole geometry contract to the new pair, and every comment/readme site that narrated the plain-text stance or the 4x2 arithmetic is rewritten to record the overturning and its provenance. The `lg` sticky text sidebar renders exactly as today. No new dependency, no `'use client'`, no active-link highlighting, no migration.
