## What this phase is

Phase 1 gave `/admin` a tile that opens `/admin`. It wears the runner's icon, so a home screen now
carries two identical squircles, one of which is the runs list and one of which is Nina's album.
The user's motive was *"i use /admin page so much"* — a tile they have to guess at is most of that
value gone.

This phase makes the admin tile **the same icon in the dark scheme**: the same committed
silhouette, the same five zone colours, drawn on `--paper` dark with the figure in `--ink` dark.

## Why that, and not new art

Three reasons, in order of weight:

1. **It is measurably more legible than the runner's tile, not merely different.** Computed with
   the WCAG relative-luminance formula over `app/globals.css`'s literal token values — and the
   formula reproduces `tools/make_icon_assets.py`'s own recorded figure of 11.9 for the light tile
   exactly, which is what makes the rest of the column trustworthy:

   | | figure vs ground | z1 | z2 | z3 | z4 | z5 |
   |---|---|---|---|---|---|---|
   | light tile (shipped) | 11.89 | 1.62 | 1.47 | 1.24 | 1.74 | 2.36 |
   | dark tile (this phase) | **16.17** | **8.48** | **9.33** | **11.04** | **7.90** | **5.82** |

   The zone bar — the part `make_icon_assets.py`'s `GROUND` comment says *"dissolves entirely"*
   against the wrong ground — separates from the dark ground by 5.8 to 11.0 where the shipped tile
   manages 1.24 to 2.36. The five segments' contrast **with each other** is unchanged, because they
   are the same five colours: `--z1`…`--z5` are defined only in `:root` in `app/globals.css` and do
   not vary by scheme. Verified, not assumed.

2. **The two grounds are 13.74 apart**, which is the number that matters for R1. A light tile and a
   dark tile are told apart at 40 px by peripheral vision; two tiles differing by a corner glyph
   are not.

3. **It costs no new art and no image API call.** `assets/icon/silhouette.png` is committed, and
   `tools/make_icon_assets.py` already draws the ground, the bar, the scale and the centring in
   code from tokens — its header calls that the division of labour on purpose. A second generated
   figure would mean an OpenRouter call, a judgement loop, and a second master to keep in step,
   to say what a scheme swap says for free. `tools/gen_app_icon.py` is not run by this phase and
   `npm run ci:openrouter-guard` stays green untouched.

### 1e. `main()`

Replace the argument parser and the write section. The geometry print stays; it is deck-independent
and it is the line that tells you the silhouette was read correctly.

```python
def main() -> None:
    parser = argparse.ArgumentParser(
        description="Compose the Run Insights app icons and write the shipped PNGs.",
        formatter_class=argparse.RawDescriptionHelpFormatter,
    )
    parser.add_argument("--deck", choices=[*DECKS, "both"], default="both",
                        help="which deck to write (default: both)")
    parser.add_argument("--dry-run", action="store_true",
                        help="print the resolved geometry and the outputs; write nothing")
    args = parser.parse_args()

    decks = list(DECKS) if args.deck == "both" else [args.deck]

    alpha = figure_alpha(SILHOUETTE)
    fig_w, fig_h = alpha.size
    aspect = fig_w / fig_h

    # The block is `aspect` wide per 1 of figure height, but taller than the figure by the gap and
    # the bar — that full ratio is what has to fit the circle.
    block_aspect = aspect / (1 + GAP_OF_FIG_H + BAR_H_OF_FIG_H)
    content_h_maskable = maskable_content_height(block_aspect)

    print(f"silhouette      {SILHOUETTE.relative_to(ROOT)}  figure {fig_w}x{fig_h}, "
          f"aspect {aspect:.3f}")
    print(f"content height  any {CONTENT_H_ANY:.3f}  ·  maskable {content_h_maskable:.3f} "
          f"(fits the {MASKABLE_SAFE_DIAMETER:.0%} safe circle)")

    if args.dry_run:
        for name in decks:
            print(f"deck {name}")
            for path, px, kind in DECKS[name]["outputs"]:
                print(f"  would write  {path}  {px}²  ({kind})")
        return

    for name in decks:
        deck = DECKS[name]
        print(f"deck {name}  ground #{bytes(deck['ground']).hex()}  "
              f"ink #{bytes(deck['ink']).hex()}")
        masters = {
            "any": compose(alpha, CONTENT_H_ANY, MASTER_PX, deck["ground"], deck["ink"]),
            "maskable": compose(
                alpha, content_h_maskable, MASTER_PX, deck["ground"], deck["ink"]
            ),
        }
        for path, image in (
            (deck["master"], masters["any"]),
            (deck["master_maskable"], masters["maskable"]),
        ):
            path.parent.mkdir(parents=True, exist_ok=True)
            image.save(path, optimize=True)
            print(f"  wrote {path.relative_to(ROOT)}  {MASTER_PX}²  {path.stat().st_size:,} bytes")

        for path, px, kind in deck["outputs"]:
            out = ROOT / path
            out.parent.mkdir(parents=True, exist_ok=True)
            masters[kind].resize((px, px), Image.LANCZOS).save(out, optimize=True)
            print(f"  wrote {path}  {px}²  ({kind})  {out.stat().st_size:,} bytes")
```

## The device check, which no command can do

Install both tiles on the iPhone: Add to Home Screen from `/` and again from `/admin`. Then, at
arm's length:

1. Two tiles, obviously different, one light and one dark.
2. The labels read "Run Insights" and "RI Admin", neither truncated with an ellipsis.
3. Tapping the dark one opens `/admin` full-screen; tapping the light one opens the runs list.
4. Neither install replaced the other.

Delete any tile installed before phase 1 first — iOS caches a manifest per install.

## What this phase must not do

- Not regenerate, resize or re-encode the runner's five icon files, or `assets/icon/master.png`,
  `master-maskable.png` or `silhouette.png`. Invariant 1, and Step 2 is the check.
- Not run `tools/gen_app_icon.py`, and not name `OPENROUTER_API_KEY` anywhere.
  `npm run ci:openrouter-guard` greps `lib/` for it and greps comments too.
- Not add a dark `ZONES` set. `--z1`…`--z5` are scheme-independent in `app/globals.css`; checked.
- Not put any icon under `public/badges/` or `public/records/`. Invariant 6 —
  `next.config.ts` serves those `immutable` for a year and would pin a regenerated tile in every
  installed home screen.
- Not add `app/admin/icon.png`. The favicon stays the app's; the docstring says why.
- Not set `metadata.icons` in `app/admin/layout.tsx`. Invariant 3 — it would delete the very file
  this phase ships.
- Not edit `app/manifest.ts`, `app/layout.tsx`, or `package.json`.
- Not write `.workflows/todos.md`, `.workflows/package_readme.md`, or the tracked orchestration
  `PLAN.md` if a coordinator is driving this set — send it the text instead.
